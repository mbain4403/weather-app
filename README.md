# Weather 2.0

A paywall-free weather console in a single self-contained `index.html` — no build step, no server, no API keys. Open the file in a browser (or serve the folder with any static host) and it runs.

## Features

- Current conditions and hourly/daily forecasts (Open-Meteo)
- Live radar and a 3D globe view
- National Weather Service alerts for the selected location
- Location search with savable places
- °F / °C toggle
- Forecast model comparison
- NOAA/NHC hurricane tracker

## This public copy

This is the shareable edition of Weather 2.0: it starts on New York City by default and contains no personal or location-specific configuration. Updated November 19, 2026 with the current fixed build (November 16, 2026).

The `client/`, `server/`, and `drizzle/` folders are the earlier November 2026 source snapshot, kept for history; the live app is the root `index.html`.
